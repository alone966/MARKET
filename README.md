# Makmart Inventory Scraper

Этот репозиторий содержит утилиту командной строки, которая автоматически собирает каталог товаров с [makmart.ru](https://makmart.ru/) с разбивкой по категориям. Скрипт выгружает артикул, наименование, описание, стоимость и остатки по складам (с акцентом на Наро-Фоминск), а также отслеживает изменения ассортимента между запусками. Результат сохраняется в удобный Excel-файл с визуальным подсветкой новинок, удалённых и изменённых позиций.

> ⚠️ Скрипт рассчитан на работу при наличии доступа к сайту makmart.ru. В окружениях без внешнего подключения (например, в песочнице) запросы будут завершаться ошибкой.

## Возможности

- Обход каталога и подкатегорий makmart.ru с соблюдением пауз между запросами.
- Сбор детальной информации о товаре: артикул, название, описание, цена, валюта, остатки по городам.
- Отдельное выделение остатков по складу в Наро-Фоминске.
- Сохранение результата в Excel (`data/makmart_inventory.xlsx`) c:
  - листом `Каталог` (основные данные);
  - листом `Изменения` (новые, удалённые и изменившиеся позиции);
  - листом `Сводка` (дата выгрузки и общее количество позиций).
- Хранение JSON-снимка (`data/last_snapshot.json`) и подсветка изменений между запусками.
- Гибкая фильтрация категорий (включение/исключение) и настройка логирования.

## Установка

1. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. При необходимости настройте прокси или заголовки в `src/makmart_parser/config.py`.

## Запуск

```bash
python -m makmart_parser scrape \
  --store "Наро-Фоминск" \
  --output data/makmart_inventory.xlsx \
  --snapshot data/last_snapshot.json \
  --log-level INFO
```

### Полезные флаги

- `--include` — перечень категорий, которые нужно включить (остальные будут пропущены).
- `--exclude` — перечень категорий, которые необходимо исключить из обхода.
- `--only` — ограничение на конкретные категории (аналог фильтрации по точному совпадению).
- `--store` — название города для отслеживания остатков (по умолчанию «Наро-Фоминск»).
- `--log-level` — уровень логирования (`DEBUG`, `INFO`, `WARNING`, ...).

Excel-файл и JSON-снимок будут созданы автоматически в папке `data/` (создаётся при первом запуске).

## Структура проекта

```
src/
  makmart_parser/
    cli.py         # точка входа и CLI
    config.py      # настройки скрапера
    excel.py       # экспорт данных и подсветка изменений
    http.py        # HTTP-клиент с ретраями и троттлингом
    models.py      # датаклассы доменной модели
    parsing.py     # извлечение данных из HTML
    scraper.py     # обход каталога и товаров
    snapshot.py    # сохранение и сравнение снимков
```

## Примечания

- Убедитесь, что использование данных соответствует правилам и условиям сайта makmart.ru.
- При первом запуске все товары будут отмечены как «новые». При повторных запусках подсветка в Excel покажет изменения количества, цены и структуры.
