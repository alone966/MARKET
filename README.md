# SKLAD_NF Telegram Bot

Телеграм-бот для продажи косметики SKLAD_NF. Проект построен на [aiogram 3](https://docs.aiogram.dev/) и включает витрину товаров, корзину, оформление заказов и выгрузку заказов в SQLite.

## Возможности

- Главное меню со ссылками на каталог, отзывы, доставку и поддержку.
- Каталог с категориями (уход за лицом, маски, парфюм, макияж) и карточками товаров.
- Корзина с возможностью добавления, очистки и быстрых покупок.
- Оформление заказа с указанием контактных данных, доставки, комментария и способа оплаты.
- Сохранение заказов в базе `data/orders.db` и уведомления администратору.
- Предустановленные тексты об оплате через СБП, YooKassa и CloudPayments.

## Подготовка окружения

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Переменные окружения

| Название        | Описание                                                         |
| --------------- | ---------------------------------------------------------------- |
| `BOT_TOKEN`     | Токен Telegram-бота от [@BotFather](https://t.me/BotFather).      |
| `ADMIN_CHAT_ID` | (Опционально) Chat ID для получения уведомлений о новых заказах. |
| `DATABASE_PATH` | (Опционально) путь к файлу SQLite. По умолчанию `./data/orders.db`. |

Создайте файл `.env` или экспортируйте переменные вручную перед запуском.

## Запуск

```bash
export BOT_TOKEN="123456:ABCDEF"  # пример
python -m bot.main
```

Бот запускается в режиме long polling. Перед стартом автоматически сбрасывается вебхук.

## Структура проекта

```
bot/
├── callbacks.py      # схемы callback-data для каталога и корзины
├── cart.py           # вспомогательные функции работы с корзиной (FSM)
├── catalog.py        # каталог товаров и описания
├── config.py         # загрузка настроек из переменных окружения
├── database.py       # SQLite-хранилище заказов
├── handlers/
│   ├── catalog.py    # каталог, корзина и оформление заказа
│   └── common.py     # /start и информационные разделы
├── keyboards.py      # reply/inline клавиатуры
├── main.py           # точка входа aiogram
├── states.py         # FSM состояния оформления заказа
└── texts.py          # тексты и рендер карточек
```

## Настройка витрины и платежей

- Отредактируйте товары в `bot/catalog.py`.
- Измените текстовые подсказки и инструкции в `bot/texts.py`.
- Для подключения реальной YooKassa или CloudPayments интегрируйте API в `process_payment_method` в `bot/handlers/catalog.py`.

## База заказов

Все оформленные заказы сохраняются в SQLite. Схема таблицы находится в `bot/database.py`. Для анализа заказов можно открыть файл `data/orders.db` любым SQLite-клиентом или подключить выгрузку в Google Sheets.
